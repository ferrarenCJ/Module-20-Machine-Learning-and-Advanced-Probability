# Knowledge Checks

## Overview

This folder contains all knowledge checks completed throughout the MIT Professional Education Data Engineering Program.

Knowledge checks are short assessments designed to reinforce key concepts introduced in each module. These activities provide an opportunity to verify understanding of technical concepts, mathematical foundations, machine learning algorithms, data engineering principles, and best practices.

---

## Purpose

Knowledge checks serve as:

- Self-assessments
- Concept reviews
- Exam preparation resources
- Learning reinforcement exercises

While many knowledge checks do not contribute directly to program completion, they provide valuable practice and immediate feedback on comprehension.

---

## Objectives

The knowledge checks help students:

- Verify understanding of module concepts
- Identify knowledge gaps
- Reinforce technical terminology
- Review formulas and methodologies
- Prepare for assignments and projects
- Build confidence in applying concepts

## Study Strategy

Before completing a knowledge check:

1. Review module notes.
2. Review video summaries.
3. Review cheat sheets.
4. Complete coding activities.
5. Review discussion assignments.

After completing a knowledge check:

1. Review incorrect answers.
2. Revisit lesson materials.
3. Update study notes.
4. Practice related exercises.
