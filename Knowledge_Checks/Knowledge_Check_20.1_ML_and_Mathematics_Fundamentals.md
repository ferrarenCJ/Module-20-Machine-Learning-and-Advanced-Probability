### Question 1

**Topic:** Cartesian Plane

If a point in Quadrant III is reflected across the Y-axis, what are the signs of the resulting point?

✅ Correct Answer:

```text
(+, -)
```

### Key Concept

A point in Quadrant III:

```text
(-, -)
```

Reflected across the Y-axis becomes:

```text
(+, -)
```

which is located in Quadrant IV.

### Question 8

**Topic:** Chain Rule

Find the derivative of:

```text
f(x) = (5x)^3
```

Do not simplify.

✅ Correct Answer:

```text
15(5x)^2
```

### Solution

Using the Chain Rule:

```text
u = 5x

f(u) = u^3

f'(u) = 3u²

du/dx = 5

3u²(5)

= 15(5x)²
```

### Question 11

**Topic:** Overfitting

Which situation indicates overfitting?

✅ Correct Answer:

```text
High accuracy on training data but low accuracy on testing data
```

### Why?

An overfit model:

- Memorizes training data
- Learns noise instead of patterns
- Does not generalize to unseen data
