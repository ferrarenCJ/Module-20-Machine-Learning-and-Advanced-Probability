# Sandbox

## Overview

This folder is used as a personal experimentation and practice area throughout the MIT Professional Education Data Engineering Program.

The Sandbox provides a safe environment for testing concepts, writing exploratory code, validating ideas, experimenting with datasets, and practicing new technologies without affecting module assignments or project deliverables.

The Sandbox serves as a workspace for:

- Practicing new tools
- Troubleshooting issues
- Building prototypes

This environment encourages curiosity, creativity, and hands-on learning.
