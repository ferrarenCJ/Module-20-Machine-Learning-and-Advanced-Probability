# Resources

## Overview

This folder contains supplemental resources, references, documentation links, datasets, articles, and study materials used throughout the MIT Professional Education Data Engineering Program.

These resources support module learning objectives and provide additional opportunities to deepen understanding of technical concepts, tools, frameworks, and industry best practices.
