# Coding Activities

## Overview

This folder contains all hands-on coding activities completed throughout the MIT Professional Education Data Engineering Program.

The coding activities are designed to reinforce concepts introduced in lectures and discussions by applying them in Python, Jupyter Notebooks, and real-world datasets.

Each activity focuses on practical implementation, problem-solving, debugging, and data analysis techniques commonly used by data engineers and data scientists.

---

## Objectives

The coding activities help develop skills in:

- Python programming
- Data analysis
- Machine learning
- Data preprocessing
- Statistical analysis
- Algorithm implementation
- Model evaluation
- Working with real-world datasets
