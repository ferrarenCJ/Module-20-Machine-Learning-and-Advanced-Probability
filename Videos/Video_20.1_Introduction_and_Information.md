## Major Topics

### Machine Learning Fundamentals

Machine Learning enables systems to learn from data and make predictions with minimal explicit programming.

### Gradient Descent

Gradient Descent is an optimization algorithm used to reduce prediction error by iteratively updating model parameters.

### Bayes Theorem

Bayes Theorem provides a mathematical framework for updating probabilities using new evidence.

### Naïve Bayes

Naïve Bayes is a probabilistic classification algorithm based on Bayes Theorem and conditional independence assumptions.

### Gaussian Naïve Bayes

Gaussian Naïve Bayes extends Naïve Bayes for continuous numeric features that follow a normal distribution.

### Scikit-Learn

Scikit-Learn is a Python machine learning library used to build, train, and evaluate machine learning models.
