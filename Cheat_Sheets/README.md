# Cheat Sheets

## Overview

This folder contains quick-reference cheat sheets created throughout the MIT Professional Education Data Engineering Program. These resources are intended to provide concise summaries of key concepts, formulas, workflows, commands, and best practices covered in each module.

The cheat sheets serve as study aids, interview preparation material, and practical references for future data engineering and machine learning projects.

---

## Purpose

The goal of these cheat sheets is to provide:

- Quick concept reviews
- Important formulas
- Common workflows
- Coding patterns
- Best practices
- Exam and assignment preparation materials

Rather than revisiting entire modules, these documents summarize the most important information in a compact format.
